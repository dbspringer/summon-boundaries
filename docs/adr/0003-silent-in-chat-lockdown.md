# Silent in Chat Lockdown

Forever runs the Mainline client with the Midnight addon restrictions. During Chat Lockdown, the text and sender of `CHAT_MSG_WHISPER` can be secret values, and `C_ChatInfo.SendChatMessage` rejects secret arguments from addon code. When `C_ChatInfo.InChatMessagingLockdown()` is true, or `issecretvalue` says the text or sender is secret, the shell returns a lockdown Decision and sends nothing. We considered queueing the whisper and replying after lockdown ends (more helpful, but it keeps a sender in memory with no way to read who it is, and a late Reply out of context reads as spam). The cost is that a Summon Request in a dungeon or encounter gets no Reply, which is probably the right outcome anyway, since the warlock is busy.
