# Decisions live in a pure core

Every choice about a whisper (is it a Summon Request, is the sender exempt, is a Cooldown or the Rate Limit in the way) is made by plain Lua 5.1 modules in `src/` that call no WoW API. A thin shell (`SummonBoundaries.lua` and the event and command files) reads the client, turns one `CHAT_MSG_WHISPER` into a plain table of facts, passes it with the time to the core, and sends the Reply when the Decision says so. This lets `busted` run each case from the spec with mock whispers in CI, with no client. We considered one event handler that does it all, as small addons usually do (less code, but every rule needs the game to test, and the anti-spam rules are the part that must not break). The cost is a few extra files and one rule to keep: the core never touches a WoW global, which luacheck enforces only loosely, so a review has to catch it.
